# CH01 纯对话跑通 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个 FastAPI 服务：SSE 流式多轮对话 + 模板化客服 Prompt + 售后描述结构化抽取，接入 GLM-5.3-Flash（OpenAI 协议）。

**Architecture:** 分层单向依赖：`api/routes` → `services` → `core`（llm/prompts/session/schemas）→ `config`。SSE 用 FastAPI `EventSourceResponse`；流式用 LangChain `astream`；裁剪用 `trim_messages`；结构化输出用 `with_structured_output(method="function_calling")`。会话存进程内存 dict。

**Tech Stack:** Python 3.13 + FastAPI + LangChain（langchain-openai ChatOpenAI）+ pydantic-settings + pytest

**Spec:** `docs/superpowers/specs/2026-10-15-ch01-pure-chat-design.md`

## Global Constraints

- 模型接入统一 OpenAI 协议；`LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` 全部走 `.env`，代码零硬编码。
- 默认值：`LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4/`，`LLM_MODEL=glm-5.3-flash`。
- `with_structured_output` 默认 `method="function_calling"`；回退链 `function_calling` → `json_mode` → **停下来问用户**，不自行换方案。
- 温度：对话 0.7 / 抽取 0；`max_tokens=512`；`HISTORY_TOKEN_BUDGET=2048`。
- 裁剪参数固定：`trim_messages(strategy="last", token_counter=count_tokens_approximately, max_tokens=HISTORY_TOKEN_BUDGET, start_on="human", end_on=("human", "ai"))`。
- SSE 事件：`token`（`{"content": str}`）/ `done`（`{"session_id": str, "finish_reason": str}`）/ `error`（`{"code": str, "message": str}`）。
- `AfterSalesInfo` 字段：`order_id` / `claim_type`（枚举 refund/return_refund/exchange/repair/compensation/complaint/inquiry/other）/ `expected_solution`，均可空。
- 密钥只进 `.env`；`.env` 与 `__pycache__` 进 `.gitignore`，禁止提交。
- 不可单测任务（Prompt 质量、抽取准确率）用标注样例 eval 替代 TDD；eval 通过率 ≥ 90% 算过。
- 所有 LangChain / FastAPI API 用法以 Context7 查证的当前文档为准（查证记录见 spec 与 dev-notes）。
- 本计划在主工作区直接执行，不建 worktree（空新仓库，无并行分支风险）。

## Review Focus

1. **session_id 首次出现（不存在）** → 应静默新建空历史正常对话，不得报错。测试：`test_session.py::test_unknown_session_starts_empty`
2. **历史超预算裁剪后** → system prompt 仍在首位、末条不是孤立 human。测试：`test_session.py::test_trim_keeps_system_first_and_no_dangling_human`
3. **message 为空/纯空白** → 422 校验错误，不得把空串打给上游。测试：`test_routes.py::test_empty_message_rejected`
4. **上游 API 报错（401/限流/超时）** → 推 `error` 事件后正常结束流，连接不挂起。测试：`test_chat_service.py::test_upstream_error_emits_sse_error_event`
5. **售后描述无订单号** → `order_id=null`，不得幻觉编造。eval 集固定含 2 条此类样例，`run_eval.py` 判分。
