### 翻车与返工（按时间序）

1. **SQLite 不认 BIGINT PRIMARY KEY 自增**：SQLAlchemy BigInteger 在 SQLite 编译为 BIGINT，非 rowid 别名 → `NOT NULL constraint failed: conversations.id`。修复：`BigInteger().with_variant(Integer, "sqlite")`（base.py 的 BigInt），MySQL 侧仍是 BIGINT。
2. **ToolExecutor 拿 ToolMessage 当字符串**：`tool.ainvoke(tool_call_dict)` 返回 ToolMessage 对象，`str()` 后是 repr。修复：取 `.content`。
3. **DDL 脚本切分踩注释里的分号**：`split(";")` 把 `-- FAQ 问答对:…数据源;ch03 起…` 注释切碎。修复：splitter 先剥离 `--` 行注释；另加 `--if-not-exists` 幂等选项。
4. **conversation_id=None 每次都新建会话**（测试暴露）：同 session_id 连续消息串不到一起，CH01 语义断裂。修复：None 时复用该用户最近「进行中」会话（补 2 条仓库测试）。
5. **pool_pre_ping 与 aiomysql 不兼容**（集成验收抓到，单测 SQLite 无此路径）：`AsyncAdapt_aiomysql_connection.ping() missing 1 required positional argument: 'reconnect'`。修复：关 pre_ping、改 `pool_recycle=3600`（短于 MySQL wait_timeout 8h 规避死连接）。
6. **eval 链路漏 system prompt**（85% → 69% 波动）：裸发 user 消息测的不是真实链路，「何时调 create_ticket」的指引就在 system prompt 里。修复：eval 用 `build_chat_prompt_with_tools()` 复刻真实链路。
7. **eval 标注修正**：「解决不了就转人工吧」原标 create_ticket——按系统设计转人工≠建工单（CH05 才分离），改标 none；「我上周买的跑鞋多少钱」有订单语境两可，改问句「你们店铺里的跑鞋一般什么价位」。
8. **create_ticket 触发不稳**：GLM 对写操作保守，「我要建个工单」偶发不选工具。prompt 强化触发条件（列举用户原话模式）后 13/13 连跑两轮 100%。
9. **环境插曲**：curl 走沙箱代理 502（加 `--noproxy '*'`）；后台起服务必须用受管后台任务，`&` 会被 shell 收尾杀掉。
