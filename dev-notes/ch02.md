### 翻车与返工

- **GLM function calling 翻案（重要，影响全章地基）**：ch01 dev-notes 结论「GLM-5.3-Flash 在 bind_tools 下不产生 tool_calls，content 直出 JSON」**不成立**。本轮双探针实测：
  - 裸调 OpenAI SDK `tools` 参数 → `finish_reason: tool_calls`；
  - LangChain `bind_tools([query_logistics]).invoke("订单1001的物流到哪了？")` → 正确返回 `{'name': 'query_logistics', 'args': {'order_id': '1001'}, 'id': 'call_-7162975688369104611', 'type': 'tool_call'}`。
  - ch01 失败疑因（记录备查）：当时走的是 `with_structured_output(function_calling)` 的 schema 转换路径，与裸 `tools` 参数路径不同；不排除上游行为变更。结论：第二章 Function Calling 地基成立，但 ch01 的 `LLM_STRUCTURED_METHOD=json_mode` 默认值保持不动（抽取路径照常），**工具路径以本轮探针为准，且集成验收必须用真实 GLM 端到端复验**。
